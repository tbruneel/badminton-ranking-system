🏸 VUB SportMix: Badminton

Badminton Elo Ranking System

A mobile-first Badminton Ranking System modeled after the SliceWin Elo System, integrated with Google Sheets and Google Apps Script, and served via GitHub Pages so it works seamlessly on mobile Chrome without Google multi-account issues.

📱 Open Live Ranking App → 📊 Open Google Sheet Backend

✨ Key Features

🎾 Separate Singles & Doubles Elo

Every player maintains an independent Singles and Doubles Elo rating, each starting at a baseline of 1000 points.

🤝 Random-Partner Doubles

Form pairs with any partner for each match. Team strength is the average of both partners' personal Doubles Elos.

🏆 Podiums, Leaderboards & History

Mobile-friendly Top 3 Podium cards, searchable Leaderboards with W/L/T records, and chronological Match History cards.

🔒 Read-Only Public + Admin Unlock

Public visitors cannot modify data. Organizers tap 🔒 Admin to unlock match logging and player management.

🧮 SliceWin Elo Calculation

1. Team Avg (Doubles): R_team1 = (R_p1 + R_p2) / 2, R_team2 = (R_p3 + R_p4) / 2
2. Expected Score: E_1 = 1 / (1 + 10 ^ ((R_team2 - R_team1) / 400))
3. Margin Multiplier: K_eff = 40 + 40 * (|Pts_1 - Pts_2| / (Pts_1 + Pts_2))
4. Rating Change: Delta_1 = ROUND(K_eff * (S_1 - E_1)), Delta_2 = -Delta_1

🔐 Security & Multi-Account Chrome Fix

  • Salted SHA-256 Password Hashing: The Admin Password is never stored in plain text in code.gs, index.html, or ScriptProperties. Only a random UUID salt (ADMIN_SALT) and SHA-256(salt + ":" + password) digest (ADMIN_PASSWORD_HASH) are stored.
  • Constant-Time Verification & Brute-Force Lockout: Hashes are compared using bitwise constant-time equality, and CacheService locks out login attempts for 15 minutes after 5 failed tries.
  • HTTPS POST-Only & Android Chrome Multi-Account Fix: Hosting index.html on GitHub Pages and calling the Apps Script backend with fetch(..., { credentials: "omit" }) prevents Android Chrome from attaching conflicting multi-account Google cookies (bypassing Google Issue #69270374).
  • Formula-Injection & Input Validation: Blocks leading =, +, -, @ characters, enforces distinct roster players and 0–30 non-tie set scores, and locks writes via LockService.getScriptLock().

🛠️ Setup & Deployment

  1. In your Google Sheet, open Extensions > Apps Script, paste code.gs into Code.gs and index.html into Index.html, and save.
  2. Reload your Google Sheet, click 🔒 Badminton Admin > Set / Change Admin Password... in the top menu bar, and set your password.
  3. In Apps Script, click Deploy > Manage deployments > Edit (✏️) > Version: New version > Deploy (Execute as: Me, Who has access: Anyone).
